# Instructions

- При работе с ESPHome использовать Python-окружение из текущей папки проекта (`.venv`).
- Python-окружение активировать один раз при первом запуске; повторная активация не требуется.
- Сборка/запуск выполняется командой: `esphome run .\JXD\jxd-pm380-e1eth-eth_v2.yaml --no-logs`.
- For ESPHome flashing commands, always use the `--no-logs` flag.
